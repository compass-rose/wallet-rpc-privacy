# 模块3.4：可视化仪表板API文档

## 概述

模块3.4提供实时监控面板、分析报告和图表展示功能，支持ECharts前端库渲染。

**基础URL**: `http://localhost:8000/api/v1`

---

## 1. 实时监控面板

### 1.1 获取当前监控状态

**端点**: `GET /dashboard/monitor/status`

**描述**: 获取当前网络捕获状态和整体指标

**请求示例**:
```bash
curl http://localhost:8000/api/v1/dashboard/monitor/status
```

**返回示例**:
```json
{
  "success": true,
  "data": {
    "active_sessions": 0,
    "total_sessions": 7,
    "capturing": false,
    "today_packets": 193,
    "today_leaks": 15,
    "capture_rate": 0.45,
    "last_capture_time": "2026-03-09T11:33:04"
  },
  "metadata": {
    "request_id": "b27ea33d-eaa7-470d-9cf7-339383f7aef2",
    "timestamp": "2026-03-09T11:33:04.086489+00:00"
  }
}
```

**字段说明**:
- `active_sessions`: 当前活跃的会话数
- `total_sessions`: 总会话数
- `capturing`: 是否正在捕获网络流量
- `today_packets`:
 今天的捕获包数
- `today_leaks`: 今天的隐私泄露事件数
- `capture_rate`: 捕获速率（包/秒）
- `last_capture_time`: 最后捕获时间

## 7. 使用示例

### 7.1 快速开始

```bash
# 1. 查看监控状态
curl http://localhost:8000/api/v1/dashboard/monitor/status

# 2. 获取最近24小时的时间线
curl "http://localhost:8000/api/v1/dashboard/reports/timeline?time_range=last_24h"

# 3. 获取时间分布热力图
curl "http://localhost:8000/api/v1/dashboard/reports/heatmap?heatmap_type=timeofday"

# 4. 获取所有图表数据（前端集成）
curl "http://localhost:8000/api/v1/dashboard/charts?time_range=last_7d"

# 5. 生成综合报告
curl -X POST "http://localhost:8000/api/v1/dashboard/comprehensive-report?time_range=last_24h"
```

### 7.2 集成到前端

1. **实时监控面板**:
   - 轮询 `/dashboard/monitor/status` 获取状态
   - 使用SSE或WebSocket订阅 `/dashboard/monitor/leaks/stream` 获取实时泄露流

2. **ECharts图表集成**:
   - 调用 `/dashboard/charts` 获取所有图表数据
   - 直接使用返回的JSON数据渲染ECharts图表
   - 支持的图表类型：timeline, pie, bar, line

3. **自定义时间范围**:
   - 所有报告和图表都支持 `time_range` 参数
   - 可选值：`last_hour`, `last_24h`, `last_7d`, `last_30d`

### 7.3 综合报告使用

综合报告API会自动并行执行以下所有测试：
- 最多3个会话的基础风险评估
- 基线对比测试（与随机/理想基线对比，行业百分位排名）
- 模拟攻击测试（使用随机森林和朴素贝叶斯分类器，同时运行聚类攻击）
- 对抗性测试（评估padding、timing_jitter、method_randomization等防御策略）

响应时间约1秒，返回完整的JSON格式报告数据。

## 12. 注意事项

1. **时间范围**: 所有时间范围基于UTC时区
2. **分页**: 泄露流接口支持分页，避免一次性返回大量数据
3. **并发**: 综合报告使用并发执行，不会阻塞单个测试的失败
4. **性能**: 建议前端缓存图表数据，避免频繁请求
5. **错误处理**: 所有API都包含详细的错误信息和错误码

## 13. 常见问题

**Q: 如何获取更多历史数据？**
A: 使用 `time_range=last_30d` 参数获取30天的数据。

**Q: 综合报告需要多长时间？**
A: 约1秒（包含所有4类测试的并发执行）。

**Q: 图表数据如何在前端使用？**
A: 直接使用 `/dashboard/charts` 返回的JSON数据，格式兼容ECharts。

**Q: 如何区分高低风险？**
A: 根据overall_score：0-33(低), 34-66(中), 67-100(高)。

**Q: 建议的数据刷新频率？**
A: 监控数据每5-10秒刷新，图表每1-5分钟刷新。
